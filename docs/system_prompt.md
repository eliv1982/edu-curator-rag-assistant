# Системный промпт — EduCurator AI

## Где находится промпт

Системный промпт реализован в коде и существует в единственном экземпляре:

| Что | Где |
|-----|-----|
| Текст промпта | `SYSTEM_PROMPT_TEMPLATE` в `src/prompt_builder.py` |
| Подстановка переменных | `build_system_prompt()` в `src/prompt_builder.py` |
| Формирование `{context}` | `format_context()` в `src/prompt_builder.py` |
| Вызов LLM | `ask_llm()` в `src/prompt_builder.py` |

Этот файл **не содержит копии текста промпта**: отдельная копия расходилась бы с кодом. Он описывает только структуру и поведение; точные формулировки смотрите в `src/prompt_builder.py`. При изменении промпта обновляйте описание ниже, если изменились роль, правила или структура.

Обоснование дизайна — в `docs/prompt_architecture.md`.

## Как формируется запрос

В OpenAI Chat API уходят два сообщения, без истории диалога:

1. `system` — шаблон с подставленными переменными
2. `user` — вопрос студента как есть

Параметры вызова заданы в `ask_llm()`: `temperature=0.3`, `max_tokens=800`; модель по умолчанию — `gpt-4o-mini` (переопределяется через `OPENAI_MODEL`).

Шаблон заполняется через `str.format()` и содержит две переменные:

- `{learner_level}` — `beginner` или `advanced`, по самостоятельному выбору студента в интерфейсе
- `{context}` — объединённые материалы, найденные для вопроса: чанки из FAISS-индекса, а для вопросов о дедлайнах и заданиях ещё и данные `assignments.csv`, поставленные в начало. Если материалов нет, подставляется фраза о том, что релевантные материалы не найдены

Few-shot-примеры в промпт не подставляются: `data/few_shot_examples.md` в рантайме не используется.

## Структура промпта

Разделы шаблона в порядке следования:

1. **Роль** — EduCurator, AI-ассистент куратора курса: помогает ориентироваться в материалах, понимать концепции, находить ресурсы
2. **Стиль** — тёплый, структурированный, честный (не выдумывает), лаконичный
3. **Уровень студента** — адаптация тона и глубины под `beginner` / `advanced`
4. **База знаний курса** — место подстановки `{context}`
5. **Чем может помочь** — объяснение концепций, вопросы о дедлайнах и структуре курса, рекомендации ресурсов, FAQ
6. **Чего не должен делать** — не менять оценки, дедлайны и статус зачисления; не обещать результат; не решать задания за студента; не выдумывать факты; не раскрывать данные других студентов
7. **Дедлайны и задания** — если в контексте есть данные `assignments.csv` с датой `ГГГГ-ММ-ДД`, использовать её как единственный источник истины и называть явно
8. **Указание источников** — просьба к модели перечислить использованные материалы в конце ответа
9. **Когда информации нет** — стандартная фраза «информации не нашёл», затем предложение, где искать, или эскалация
10. **Эскалация к куратору-человеку** — условия передачи вопроса человеку и контакт куратора (вымышленный адрес на `example.com`)
11. **Язык ответов** — русский, если студент не попросит иначе

## Что промпт гарантирует, а что нет

- Правила (границы роли, отказ, эскалация, формат источников) — это **инструкции модели**, а не программные проверки. Следование им зависит от модели и не покрыто автоматическими тестами; проверка выполняется вручную (сценарии — в `README.md`).
- Строку источников в конце ответа пишет сама модель. Она не сверяется с контекстом и не является подтверждённой цитатой. Блок «Найденные материалы» в UI — отдельный список найденных материалов (см. `docs/rag_schema.md`).
- Порога релевантности нет: в `{context}` всегда попадает top-K чанков, поэтому решение «в материалах этого нет» принимает модель.

## Примечания для тех, кто поддерживает проект

- Сохраняйте плейсхолдеры `{context}` и `{learner_level}`; любые другие фигурные скобки в шаблоне нужно удваивать из-за `str.format()`
- Оставляйте место в контекстном окне для найденных чанков и ответа
- Инструкции по безопасному изменению промпта — в `docs/update_guide.md`, раздел 4
