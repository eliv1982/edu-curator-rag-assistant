## Как пользоваться этим разделом

Ресурсы разделены по уровню подготовки. **Начинающим** рекомендуется начать с раздела «Для начинающих» и только потом переходить к среднему уровню. **Продвинутые** могут сразу переходить к разделам «Продвинутый уровень» и «Исследования».

## Ресурсы для начинающих

### Бесплатные курсы и обучающие материалы

- **[Elements of AI](https://www.elementsofai.com/)** — Бесплатный вводный курс по основам AI без математики. Отличная отправная точка для полных новичков. *(Университет Хельсинки)*
- **[ChatGPT Prompt Engineering for Developers](https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/)** — Бесплатный мини-курс от DeepLearning.AI и OpenAI. Охватывает zero-shot, few-shot, CoT-промптинг с практическими примерами кода.
- **[Введение в генеративный AI от Google](https://www.cloudskillsboost.google/course_templates/536)** — 45-минутный обзор концепций генеративного AI для новичков. *(Google Cloud)*
- **[AI for Everyone](https://www.coursera.org/learn/ai-for-everyone)** — Нетехнический курс Эндрю Ына о применении AI в бизнесе. *(Coursera, доступно бесплатно в режиме аудита)*

### Чтение для начинающих

- **«AI Snake Oil» Арвинда Нараянана и Сайяша Капора** — Доступная книга о том, что AI умеет и не умеет, и как распознать хайп вокруг AI. Отлично подходит для выработки критического мышления.
- **Руководство OpenAI по prompt engineering** — Официальная документация OpenAI с примерами. URL: https://platform.openai.com/docs/guides/prompt-engineering
- **Руководство Anthropic по Claude** — Практические советы по промптингу. URL: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview

### Инструменты для практики (начинающие)

- **ChatGPT (бесплатный тариф)** — Тренируйте промптинг без настройки окружения. URL: https://chat.openai.com
- **Claude (бесплатный тариф)** — Альтернативная LLM с другим стилем ответов. URL: https://claude.ai
- **Google Gemini** — LLM от Google, хороша для мультимодальных экспериментов. URL: https://gemini.google.com
- **Yandex GPT** — Российская языковая модель, доступна через Яндекс 300. URL: https://ya.ru/ai/gpt

## Ресурсы среднего уровня

### Курсы и практикумы

- **[LangChain for LLM Application Development](https://www.deeplearning.ai/short-courses/langchain-for-llm-application-development/)** — Практическое введение в LangChain. *(DeepLearning.AI)*
- **[Building Systems with the ChatGPT API](https://www.deeplearning.ai/short-courses/building-systems-with-chatgpt/)** — Создание многошаговых AI-пайплайнов. *(DeepLearning.AI)*
- **[Vector Databases: from Embeddings to Applications](https://www.deeplearning.ai/short-courses/vector-databases-embeddings-applications/)** — Охватывает FAISS, Pinecone и основы векторного поиска. *(DeepLearning.AI)*

### Чтение среднего уровня

- **[Руководство по prompt engineering](https://www.promptingguide.ai/)** — Обширное руководство, поддерживаемое сообществом, охватывающее все основные техники промптинга.
- **Официальная документация LangChain** — URL: https://python.langchain.com/docs/introduction
- **Документация FAISS** — URL: https://faiss.ai/

### Проекты среднего уровня для практики

- Создайте персональный Q&A по документам с LangChain + FAISS (аналогично заданию модуля 5)
- Соберите библиотеку шаблонов промптов для ваших частых задач
- Создайте многоходового чат-бота с памятью диалога через OpenAI API

## Продвинутые ресурсы

### Углублённые курсы

- **[CS224N: NLP с глубоким обучением](https://web.stanford.edu/class/cs224n/)** — Аспирантский курс по NLP Стэнфорда, доступны записанные лекции бесплатно. Требует линейной алгебры и Python.
- **[Курс NLP от Hugging Face](https://huggingface.co/learn/nlp-course/)** — Бесплатный практический курс по трансформерам, файн-тюнингу и деплою. *(Hugging Face)*
- **[Full Stack LLM Bootcamp](https://fullstackdeeplearning.com/llm-bootcamp/)** — Production-ориентированная разработка LLM: от промптинга до деплоя.

### Продвинутое чтение и исследования

- **«Attention Is All You Need» (Vaswani et al., 2017)** — Статья о трансформерах. URL: https://arxiv.org/abs/1706.03762
- **«Language Models are Few-Shot Learners» (Brown et al., 2020)** — Статья о GPT-3, основа для few-shot промптинга. URL: https://arxiv.org/abs/2005.14165
- **«Chain-of-Thought Prompting Elicits Reasoning in Large Language Models» (Wei et al., 2022)** — URL: https://arxiv.org/abs/2201.11903
- **«Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks» (Lewis et al., 2020)** — Оригинальная статья о RAG. URL: https://arxiv.org/abs/2005.11401
- **Блог Лилиан Вэн** — Отличные технические разборы LLM и промптинга. URL: https://lilianweng.github.io

### Продвинутые инструменты и фреймворки

- **LlamaIndex** — Альтернатива LangChain для RAG-пайплайнов. URL: https://www.llamaindex.ai/
- **DSPy** — Фреймворк для программирования (не промптинга) языковых моделей. URL: https://dspy.ai/
- **Weights & Biases (W&B)** — Отслеживание экспериментов для оценки LLM. URL: https://wandb.ai
- **RAGAS** — Фреймворк для оценки качества RAG-пайплайнов. URL: https://docs.ragas.io
